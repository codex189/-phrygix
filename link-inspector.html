This is not a malware or phishing safety scan. A decoded URL can still be dangerous. The tool does not visit destinations or follow live HTTP redirects.

How it works

Private by design. No URL submission or external lookup.

01 URL decoding

Extracts embedded destinations from recognized query parameters, such as url, target and redirect_uri.

02 Tracking cleanup

Removes common marketing parameters such as utm_*, fbclid and gclid.

03 Transparent output

Shows the steps taken and lets you copy the resulting URL.

04 Honest limitations

Cannot resolve shortened URLs such as bit.ly, inspect server redirects or determine whether a link is safe.

Some sites use tracking-like parameters for functionality. Review the cleaned link before using it.
