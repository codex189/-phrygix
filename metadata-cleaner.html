PRIVACY FIRST

Metadata Studio

All processing runs in your browser. Images are not uploaded.

  • View: inspect original JPEG EXIF, available WebP EXIF, and PNG text metadata.
  • Edit: edit date, time, GPS coordinates, camera, author, copyright and custom fields.
  • Clean: re-encode images without copying source metadata.

Two-layer signature

Edited PNGs include a discoverable PHRYGIX metadata signature and an invisible pixel watermark. The verifier can check both.

Important: Editing exports a PNG with PHRYGIX-specific metadata; standard EXIF/GPS tags and arbitrary original metadata are not preserved. Original JPEG EXIF is displayed and common fields are prefilled when present. Neither watermark is unremovable. Recompression or editing can destroy the pixel watermark. Clean mode deliberately produces files without either signature.
