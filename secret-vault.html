PRIVATE NOTE SHARING GUIDE

Free Encrypted Notes and One-Time Secret Links

Use PHRYGIX Secret Vault to create private notes, share sensitive text, and generate expiring links. Notes are encrypted in your browser before upload. This service does not provide permanent file storage, a separate password feature, or a guarantee that a shared link stays confidential.

Create Private Notes with Expiring Links

Create a private note and choose an expiry of 1 hour, 24 hours, or 7 days. The encrypted note is stored until it expires or is retrieved, whichever comes first.

Send Self-Destructing Messages Online

Each PHRYGIX Secret Vault link is limited to one retrieval. Once opened, the secret is consumed, so the same link cannot be used to retrieve it again.

Share Sensitive Text with One-Time Links

Share text privately through a single-use URL. The encryption key is contained in the link fragment; anyone with the complete link may decrypt the note, so share it carefully.

Encrypted Secret Sharing with AES-GCM

Your browser encrypts the note with a freshly generated AES-GCM key before sending ciphertext to the service. Secret Vault does not offer a separate password-protection setting.

Private Secret Sharing Without an Account

Create an encrypted text note without registering for an account. This tool is for short messages and text, not file uploads or long-term cloud storage.

Secret Vault Frequently Asked Questions

What is a private note link?

It is a shareable URL that lets a recipient retrieve an encrypted note. Treat the complete URL as sensitive because it includes the decryption key.

How do I send a self-destructing message?

Enter text, select an expiry period, create the encrypted link, and send it to the intended recipient. The note can be retrieved only once.

Are Secret Vault notes encrypted?

The current browser code uses AES-GCM to encrypt note text locally before uploading ciphertext. Security also depends on safe link sharing, device security, and the deployed backend.

Can I create a one-time secret link?

Yes. The tool currently limits each secret to one retrieval.

When does a private note expire?

You can select 1 hour, 24 hours, or 7 days. A note may disappear earlier if someone retrieves it.

Can I password-protect a secret note?

There is no separate password field in the current tool. Access depends on possession of the complete secret link.

Can I share encrypted files with Secret Vault?

No. The current tool supports encrypted text notes, not file uploads or permanent file storage.

Does a one-time link guarantee nobody else can read my note?

No. Anyone who obtains the complete link may be able to open it first. Automated link scanners can also consume one-time notes. Share links through trusted channels.
