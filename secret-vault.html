CLIENT-SIDE ENCRYPTION

How it works

  • A random 256-bit AES key is generated on your device.
  • Only encrypted text is stored by the backend.
  • The key stays in the URL fragment and is not included in ordinary HTTP requests.
  • The server expires notes and allows only one retrieval.
Privacy note

Anyone with the full link can decrypt the note. Don't share links through untrusted channels. Link scanners may consume one-time notes. Avoid third-party analytics or ads on this page.

Requires the Phrygix /api/secrets backend. The HTML alone cannot host shareable secrets.
